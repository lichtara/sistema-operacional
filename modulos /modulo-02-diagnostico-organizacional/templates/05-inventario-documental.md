# 1. Finalidade

Este documento orienta o inventário e a análise dos documentos utilizados em diagnósticos organizacionais do Estúdio LICHTARA.

O inventário documental permite compreender:

* quais documentos existem;
* onde estão armazenados;
* quem responde por eles;
* para que foram criados;
* qual versão está vigente;
* quem os utiliza;
* como são atualizados;
* se correspondem à prática organizacional;
* que informações podem oferecer ao diagnóstico;
* quais lacunas, contradições ou riscos documentais estão presentes.

Sua função não é apenas produzir uma lista de arquivos.

O inventário deve ajudar a compreender a relação entre:

* documentos;
* conhecimento;
* processos;
* decisões;
* responsabilidades;
* ferramentas;
* comunicação;
* memória institucional;
* operação real.

---

# 2. Princípios da análise documental

## 2.1 A existência do documento não comprova sua utilização

Um procedimento pode existir e não ser:

* conhecido;
* acessado;
* compreendido;
* utilizado;
* atualizado;
* compatível com a prática.

O inventário deve diferenciar:

* documento existente;
* documento vigente;
* documento conhecido;
* documento utilizado;
* documento efetivamente orientador.

---

## 2.2 O documento não representa sozinho a realidade

Documentos registram:

* intenções;
* decisões;
* regras;
* versões;
* narrativas;
* resultados;
* acordos.

Eles não demonstram automaticamente como o trabalho acontece.

Quando necessário, a análise documental deve ser comparada com:

* entrevistas;
* observação;
* sistemas;
* dados;
* materiais produzidos;
* experiência dos clientes.

---

## 2.3 Versão e temporalidade são essenciais

Um documento sem:

* data;
* versão;
* autoria;
* responsável;
* histórico;

pode apresentar limitações de rastreabilidade.

A análise deve verificar se o conteúdo ainda representa o contexto atual.

---

## 2.4 Ausência de documento não significa ausência de conhecimento

O conhecimento pode existir de forma:

* oral;
* prática;
* informal;
* distribuída;
* incorporada à experiência das pessoas.

A ausência documental pode indicar risco de continuidade, mas não deve ser confundida com inexistência da capacidade.

---

## 2.5 O inventário deve ser proporcional

Não devem ser catalogados documentos sem relação com:

* questão diagnóstica;
* escopo;
* decisão apoiada;
* processo analisado;
* risco relevante;
* necessidade de contexto.

---

## 2.6 Conteúdo e uso são dimensões diferentes

Um documento pode possuir conteúdo de alta qualidade e baixo uso.

Também pode ser amplamente utilizado, mas apresentar:

* informações incorretas;
* versão desatualizada;
* linguagem ambígua;
* ausência de responsáveis;
* conflito com outros documentos.

---

## 2.7 Documentação não deve ser confundida com burocracia

O diagnóstico deve avaliar se o documento:

* preserva conhecimento;
* reduz ambiguidade;
* apoia decisões;
* orienta atividades;
* facilita continuidade;
* protege a organização.

Documentos sem função clara podem aumentar complexidade sem produzir capacidade.

# 8. Classificação de sensibilidade

Cada documento deve receber uma classificação compatível com seu conteúdo.

## Pública

Pode ser divulgada sem risco relevante.

## Interna

Destinada ao funcionamento da organização.

## Confidencial

A divulgação pode gerar risco:

* comercial;
* estratégico;
* reputacional;
* contratual;
* operacional.

## Sensível

Envolve, por exemplo:

* dados pessoais;
* saúde;
* informações financeiras;
* conflitos;
* credenciais;
* propriedade intelectual;
* estratégia crítica;
* dados de clientes;
* informações jurídicas.

## Regra

A classificação mais elevada deve prevalecer quando o documento possuir conteúdos de categorias diferentes.

# 9. Identificação dos documentos

Cada documento deve receber um identificador.

Utilizar:

```text
DOC-NNN
```

### Exemplos

```text
DOC-001
DOC-002
DOC-003
```

Quando necessário, utilizar o diagnóstico como prefixo:

```text
DIA-2026-001-DOC-001
```

O ID deve permanecer estável, mesmo quando:

* o título mudar;
* a localização mudar;
* uma nova versão surgir;
* o documento for substituído.

Novas versões podem receber o mesmo ID documental com indicação de versão, desde que representem continuidade do mesmo documento.

# 13. Avaliação de atualidade

## Critérios

Um documento é considerado atual quando:

* representa o contexto presente;
* contém informações vigentes;
* está alinhado ao processo utilizado;
* possui responsáveis válidos;
* corresponde às ferramentas atuais;
* não foi substituído por versão posterior.

## Avaliação

| Documento | Atualidade           | Evidência | Impacto |
| --------- | -------------------- | --------- | ------- |
| DOC-001   | Alta / Média / Baixa |           |         |
| DOC-002   |                      |           |         |

## Classificações

### Alta

O documento representa adequadamente a realidade atual.

### Média

Parte do conteúdo permanece válida, mas existem elementos desatualizados ou não verificados.

### Baixa

O documento não representa mais o processo, a estrutura, a oferta ou o contexto atual.

### Não determinada

Não existem informações suficientes para avaliar.

# 28. Utilidade diagnóstica

## Alta

O documento:

* responde diretamente a questões relevantes;
* possui origem e contexto identificáveis;
* representa o período analisado;
* pode ser comparado com outras fontes.

## Moderada

O documento:

* oferece contexto;
* possui limitações;
* está parcialmente desatualizado;
* exige triangulação significativa.

## Baixa

O documento:

* possui pouca relação com a questão;
* não apresenta origem clara;
* está desatualizado;
* contém informação incompleta;
* não pode ser adequadamente verificado.

## Sem utilidade para este diagnóstico

O documento pode continuar tendo valor organizacional, embora não contribua para a investigação atual.

Retirar da operação sem eliminar a memória histórica.

Eliminar, mediante autorização e critérios adequados.

Produzir documento necessário para uma função real.
